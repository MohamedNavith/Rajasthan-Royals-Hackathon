## 🔬 2. Analysis Methodology: Quantifying Pressure & Reliability

Rather than evaluating raw domestic averages or unweighted strike rates, our model evaluates player performance across **200,999 balls (2022–2026)** using an empirical **Context-Aware Pressure Framework**:

```
+----------------------------------------------------------------------------------------------------+
|                                    PRESSURE IDENTIFICATION ENGINE                                  |
+----------------------------------------------------------------------------------------------------+
| 1. Win Probability Leverage Index (WPLI):                                                          |
|    Derived via a gradient-boosted Win Probability model trained on historical T20 match states.     |
|    Deliveries with Normalized Leverage > 1.50 are classified as High Pressure (where ball outcomes|
|    cause dramatic swings in match win probability).                                                |
|                                                                                                    |
| 2. Contextual Target Index (CTI):                                                                  |
|    Applied to 2nd innings chases where Required Run Rate (RRR) exceeds 10.0 RPO.                   |
|                                                                                                    |
| 3. Late-Close Finish (LCF):                                                                        |
|    Deliveries in overs 16–20 where the victory margin is ≤ 24 runs or wickets in hand ≤ 3.         |
|                                                                                                    |
| Total deliveries analyzed: 200,999 | High-Pressure Deliveries isolated: 32,593 balls.              |
+----------------------------------------------------------------------------------------------------+
```

### The Composite Pressure Reliability Index (0–100 Scale)
Every player is evaluated across three weighted pillars:
1. **Context-Adjusted Value Added (40%):** Runs Over Expected ($\text{ROE}$) for batters; Runs Saved vs Baseline for bowlers; Win Probability Added ($\text{WPA}$).
2. **Pressure Performance Delta (35%):** Strike Rate Delta ($\Delta \text{SR} = \text{SR}_{\text{pressure}} - \text{SR}_{\text{normal}}$) and Economy Delta ($\Delta \text{Econ} = \text{Econ}_{\text{normal}} - \text{Econ}_{\text{pressure}}$).
3. **Consistency & High-Pressure Volume (25%):** Bootstrapped 95% Confidence Intervals across match samples to reward repeatable clutch performers over small-sample outliers.
